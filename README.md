# SplitSmart - Додаток для розподілу витрат

## Як почати роботу для розробників:

1. Клонуйте репозиторій:
   \`\`\`bash
   git clone <посилання*на*репозиторій>
   cd SplitSmart
   \`\`\`

2. Налаштування Бекенду (Python / FastAPI):
   - Перейдіть у папку бекенду: `cd backend`
   - Створіть та активуйте віртуальне середовище:
     - Windows: `python -m venv venv` та `venv\Scripts\activate`
   - Встановіть залежності: `pip install -r requirements.txt`
   - Створіть локальну базу даних у MySQL Workbench: `CREATE DATABASE splitsmart_db;`
   - Створіть файл `.env` на основі `.env.example` та вкажіть свій локальний пароль від MySQL.

3. Налаштування Фронтенду (React):
   - Перейдіть у папку фронтенду: `cd frontend`
   - Встановіть залежності: `npm install`
     \`\`\`git add .

Виконайте ці три кроки, і ваше середовище стане повністю автономним, чистим та готовим для спільної командної роботи! Дайте знати, як усе зробите, і ми зафіксуємо це першим комітом на GitHub.
